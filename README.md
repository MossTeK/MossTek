I’m a systems and DevOps engineer focused on Linux infrastructure, NixOS, and VoIP/UCaaS platforms. I build automation and tools that make fleets easier to configure, deploy, and operate.

## What I work on

- Linux and Kubernetes infrastructure
- NixOS configuration and fleet management
- GitOps and DevOps automation
- VoIP systems and PBX/UCaaS tooling
- Identity, networking, and security

## What I’m building

I’m developing a NixOS fleet management platform that configures multiple machines from a single flake in a monorepo. It includes a service for scheduling and managing systemd services, along with automation for coordinating active passive HA of these services across the fleets worker nodes.

The project is private and still evolving. I use it to explore practical ways to manage a group of NixOS systems with declarative configuration and repeatable operations.
